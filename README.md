# OldCat — Telegram Mini App вейп-шопа

Витрина вейп-шопа **OldCat** в виде Telegram-бота с мини-приложением (Telegram WebApp):
каталог, избранное, корзина, промокоды, оформление заказа без предоплаты, профиль
с историей заказов и админ-панель. Реальная онлайн-оплата не подключена — заказ
уходит менеджеру, дальше всё как в магазине: «зашёл → выбрал → забрал».

Все файлы лежат плоско в корне репозитория — ничего распаковывать не нужно,
просто загрузите папку целиком на GitHub.

## Состав репозитория

```
main.py           — Flask-сервер: мини-апп, Telegram-бот (webhook) и API админ-панели
index.html        — интерфейс мини-приложения (18+ гейт, hero, каталог, корзина, заказ)
admin.html        — админ-панель (товары, заказы, вопросы, промокоды)
products.json     — каталог (админка читает и пишет в этот файл)
orders.json       — заказы (создаётся автоматически)
uploads/          — фото товаров, загруженные из админки
requirements.txt  — python-зависимости
Procfile          — команда запуска для Render
render.yaml       — опциональный blueprint для Render
```

### Логотип

Анимированный логотип OldCat (чёрный кот в тыкве-джеке: моргает, машет лапкой, виляет хвостом; летучая мышь и звёзды) нарисован как SVG-спрайт `#oldcat-logo` и вшит в `index.html` и `admin.html` — отдельных файлов не нужно. Его можно заменить на фирменный логотип, подменив содержимое `<symbol>`.

## 1. Создайте бота

1. Откройте [@BotFather](https://t.me/BotFather) → `/newbot`, задайте имя (например, «OldCat») и username.
2. Сохраните выданный **токен** (`BOT_TOKEN`).
3. `/setuserpic` → загрузите логотип OldCat.

## 2. Загрузите код на GitHub

Создайте репозиторий и загрузите все файлы из этой папки в корень.

## 3. Разверните на Render

1. [render.com](https://render.com) → **New → Web Service**, подключите репозиторий.
2. Сборка определится по `Procfile`, либо вручную:
   - **Build command:** `pip install -r requirements.txt`
   - **Start command:** `gunicorn main:app --bind 0.0.0.0:$PORT`
3. Переменные окружения (**Environment**):
   - `BOT_TOKEN` — токен из BotFather
   - `ADMIN_PASSWORD` — пароль для входа в админ-панель
   - `ADMIN_CHAT_ID` — ваш Telegram ID (узнать: [@userinfobot](https://t.me/userinfobot)); можно несколько через запятую: `111111,222222`. Эти аккаунты получают уведомления о заказах и кнопку «Панель администратора» в `/start`
   - `SHOP_CONTACT` — Telegram-аккаунт менеджера без `@` (по умолчанию `Old_cat2`); на него ведут кнопки «Написать менеджеру»
   - `WEBHOOK_URL` — необязательно; Render сам передаёт `RENDER_EXTERNAL_URL`
4. После первого старта вебхук Telegram устанавливается автоматически.

## 4. Проверьте бота

`/start` → «🐈‍⬛ Открыть OldCat». Первым делом покажется экран «Тебе есть 18?» — после
подтверждения откроется каталог. Добавьте товар в корзину и оформите заказ: покупателю
придёт подтверждение (номер вида `OldCat-12`), администраторам — уведомление.

## 5. Админ-панель

`https://ваш-адрес.onrender.com/admin` (или кнопка в боте для администратора).

- **Товары** — название, категория (например: Одноразки / Под-системы / Жидкости), цена,
  старая цена, бейдж (Хит / В тренде / Скидка / В наличии), **вкусы / цвета** через запятую,
  описание, несколько фото. Без фото показывается цветная плашка с короной (6 оттенков).
- **Заказы** — состав, сумма, контакты, статусы (Новый / Связались / Выполнен / Отменён),
  сообщения покупателю прямо из карточки заказа.
- **Вопросы** — вопросы покупателей по товарам и ответы в Telegram.
- **Промокоды** — процент или фиксированная сумма, мин. сумма заказа, лимит использований.

`products.json` содержит актуальный каталог из таблицы наличия (вкладка «ДЕВАЙСЫ»):
39 позиций, категории — бренды (Elf Bar, Geek Vape, Vaporesso, Smoant, Voopoo, Lost Vape, Rincoe)
и «Комплектующие». В цене показывается цена со скидкой, прежняя цена зачёркнута, на крупных
скидках (от 10%) стоит бейдж «Скидка». Цвета из таблицы лежат в поле «вкусы / цвета». Фото
добавьте через `/admin`.

## CRM: история заказов клиента

Каждый заказ сохраняет `telegram_id` и `username` покупателя (сервер берёт их из подписанных
данных Telegram WebApp `init_data`, а если их нет — из `tg_user`). Прежние поля
`customer_chat_id` / `customer_username` остаются для совместимости, а старые заказы
дополняются новыми полями автоматически при старте.

Поиск для админки (заголовок `X-Admin-Password`):

```
GET /api/admin/customer-orders?query=123456789   # по Telegram ID
GET /api/admin/customer-orders?query=@username   # по username (регистр не важен)
```

Ответ: `customer` (ID, username'ы, имена, телефоны), `stats` (`orders_count`, `total_amount`,
`cancelled_count`, `total_amount_without_cancelled`, `average_order`, даты первого и последнего
заказа) и `orders` (дата, состав, `delivery_label`, скидка, итог, статус). Поиск по username
находит также заказы того же клиента, сделанные под прежним username.

Способ получения передаётся в `/api/order` полем `delivery_method` (`pickup` или `delivery`).
Если фронтенд его не присылает, в ответе будет «Не указан».

## Что в редизайне

- полностью новый визуальный стиль, логотип и тексты под вейп-шоп;
- экран подтверждения 18+ при первом входе (запоминается на устройстве) и предупреждение
  о никотине в подвале и в приветствии бота;
- hero «Выбрал → заказал → забрал» с преимуществами магазина (отзывы, только оригинал,
  работа по Владимиру, оплата наличными или переводом, индивидуальный заказ);
- кнопка «Написать менеджеру» (в приложении и в боте);
- вместо размеров — «вкусы / цвета»; номера заказов — `OldCat-…`.

> Перед запуском проверьте требования законодательства вашего региона к продаже и
> дистанционной торговле никотиносодержащей продукцией.

## База данных Neon (товары, заказы, фото)

Все данные — товары, заказы, вопросы, промокоды и загруженные фото — хранятся в Postgres на [Neon](https://neon.tech),
поэтому не пропадают при рестарте и редеплое на Render (диск за деньги не нужен).

1. На [neon.tech](https://neon.tech) создайте проект → скопируйте **Connection string**
   (вида `postgresql://user:pass@ep-xxx.neon.tech/neondb?sslmode=require`).
2. В Render → **Environment** добавьте переменную `DATABASE_URL` с этой строкой и перезапустите сервис.
3. Таблицы создаются автоматически. При первом запуске текущие `products.json` (и `orders.json`,
   `questions.json`, `promos.json`, `uploads/`, если есть) переносятся в базу один раз.
   Дальше `products.json` — только стартовый набор; источник правды — база.

Без `DATABASE_URL` приложение работает по-старому, на JSON-файлах (подходит для локального запуска).

**Скрыть / показать товар.** В админке у каждой карточки есть кнопка «Скрыть» — товар исчезает из
магазина, но остаётся в базе; кнопка «Показать» возвращает его. Скрытые товары помечены тегом «Скрыт».

## Постоянное хранилище без Neon

Если `DATABASE_URL` не задан: на **бесплатном** плане Render диск не сохраняется между рестартами и деплоями —
`products.json`, `orders.json` и `uploads/` пропадут. Для постоянной работы подключите
платный **Persistent Disk** (блок `disk:` в `render.yaml`) с путём монтирования в корень проекта.

Бесплатный инстанс также засыпает без трафика и просыпается несколько секунд на первом запросе.

## Локальный запуск (по желанию)

```bash
pip install -r requirements.txt
export BOT_TOKEN=your_token
export ADMIN_PASSWORD=secret
export WEBHOOK_URL=https://ваш-туннель.example  # например ngrok
python main.py
```

## Уведомление о заказе и быстрый переход к истории клиента

В уведомлении администратору о новом заказе есть строка
`Покупатель: <ID> | @<username>` (если username нет — «Юзернейм не указан»,
если нет ID — «ID не указан») и inline-кнопка «🔍 Посмотреть историю заказов».
Кнопка открывает `/admin?customer=<Telegram ID или @username>`: админка сама
переходит на вкладку «Заказы» и запускает поиск клиента (после ввода пароля,
если вы ещё не вошли). Кнопка не добавляется, если не задан `WEBHOOK_URL`
или у заказа нет ни ID, ни username.



## Умный поиск

Строка «Найти товар…» над каталогом открывает полноэкранный поиск (всё внутри `index.html`):

- мгновенная выдача по мере ввода, подсветка совпадений, поиск по названию, бренду, категории и цвету/варианту;
- исправление опечаток и неверной раскладки («удаифк» → ELFBAR), транслит («элфбар», «акб» ↔ akb);
- умные запросы: `xros до 2000`, `от 3000`, `скидки`, `хиты`;
- подсказки, недавние запросы (хранятся на устройстве), «Хиты», «Вы смотрели», быстрые фильтры, бренды и категории;
- фильтры и сортировка внутри выдачи, избранное прямо из результатов, голосовой ввод (где поддерживается), клавиши ↑ ↓ Enter Esc и `/`.
